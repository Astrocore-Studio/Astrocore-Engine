## AC-VS1 (раздел 22) — пункт за пунктом

| № | Требование | Статус |
| --- | --- | --- |
| 1 | Здание: grid-стены/перекрытия **и хотя бы один freeform mesh** | стены и перекрытия — да; freeform (GLB) — **нет** |
| 2 | Перспективная камера, непрерывные лестницы, коллизии | **нет** (нет клиента, лестниц и физики) |
| 3 | Два клиента на одном headless-сервере, 2 billboard-персонажа | **частично**: две реплики мира сходятся по операциям; сокетов и рендера нет |

| 5 | Разрушение стены доходит до обоих клиентов: геометрия, коллизии, видимость | **частично**: операция реплицируется и применяется, dirty-флаги GEOMETRY/COLLISION выставляются; коллизий и видимости как потребителей нет |
| 6 | Навигация обновляется, ревизии синхронизированы | **да** (запрос пути читает канонический мир; кэш тайлов — нет) |
| 7 | Сохранение + перезапуск восстанавливают изменения | **да** (тесты persistence, server, vertical-slice) |
| 8 | Мини-редактор | **нет** |
| 9 | Headless-сервер без GPU/окна | **да** (`check-headless.sh` в CI) |
| 10 | Граничные случаи: чанки, этажи, ID, невалидный пакет | **да** |
| 11 | Согласованность осей | **частично**: геометрия, навигация, спрайты — да; физика — после подключения Avian |

## Известные ограничения и долги

* Геометрия: внутренние грани между соседними стенами не удаляются, углы не скругляются.
* Топология и навигация работают в пределах одного этажа.
* Журнал синхронно вызывает `sync_data` на каждую операцию — достаточно для среза,
  для высокой нагрузки нужна пакетная запись.
* `content_hash` — FNV-1a по JSON, не криптографический.
* Бюджеты производительности (AC-013) не измерялись: нет репрезентативных сцен и эталонного железа.
* Лицензия репозитория не выбрана — решение владельца проекта.
* Версии: `bevy_egui 0.43.1` проверена только по метаданным реестра, не сборкой.
