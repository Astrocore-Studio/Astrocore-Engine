## Известные ограничения и долги (честно)

* **Studio:** нет браузера ресурсов с превью, терраин-кистей в интерфейсе, горячей перезагрузки;
  `EditorExtension` определён в API, но окно его не показывает; взаимодействие мышью (в том числе
  гизмо) проверено только логикой `StudioState`, не живым вводом.
* **Avian3D и Lightyear не используются** (совместимы по версиям, ADR-0002). Физика —
  собственный слой на запечённых коробках: нет динамических тел, нет транспортных средств,
  нет произвольных форм (только габаритные ящики, ступени и срезы пандуса).
* **Транспорт:** есть TCP (без шифрования) и шифрованный UDP (упрощённый Noise NK: статический
  ключ сервера закрепляется клиентом, X25519 + HKDF-SHA256 + ChaCha20-Poly1305, окно повторов).
  Протокол собственный и не прошёл внешнего криптоаудита; нет дельт, сжатия, учётных записей
  и смены ключа сервера без перевыпуска закреплённого ключа.
* **Рендер:** цвета-заглушки вместо материалов билда, у каждого спрайта свой материал,
  нет LOD-мешей, occlusion culling, инстансинга и texture arrays/атласов; дальность отрисовки —
  простое скрытие регионов; статистика рендера — оценка по сцене, без GPU-таймеров; GLB-модели читаются из папки
  `--assets` (`ns:a/b` → `ns_a_b.glb`), без файла рисуется габаритный ящик; рельеф рисуется
  одним цветом без текстур; измерения рендера не проводились (нет GPU).
* Топология и навигация — в пределах этажа; лестницы моделируются переходами между этажами.
* Импорт SS14 (RSI-спрайты читаются; YAML-прототипы, карты и импортёры) — отдельный адаптер, не сделан.
* Миграция динамического состояния при обновлении авторской карты (отчёт о конфликтах) не сделана.
* Не реализованы: вода как объём, дороги-сплайны как отдельные сущности (есть кисть-дорога),
  скриптовые графы, мультипользовательское редактирование, WASM-моды, сборка отдельных
  клиента и сервера «из Studio».
* Журнал синхронно вызывает `sync_data` на каждую операцию; `content_hash` — FNV-1a, не криптографический.
* Лицензия: обычная проприетарная, все права защищены (`LICENSE`).
* Отправка в удалённый репозиторий не выполнена: `git push` отклоняется (403, приложению Claude
  не выданы права на `Astrocore-Studio/Astrocore-Engine`); работа лежит в локальных коммитах.
