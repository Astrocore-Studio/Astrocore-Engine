# План тестирования

## Обязательные проверки (правило 4 раздела 26)

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
./scripts/check-headless.sh
```

То же выполняет CI (`.github/workflows/ci.yml`) + дымовой запуск сервера.

## Что покрыто

| Область | Проверки |
| --- | --- |
| Координаты | правосторонность Y-up; чанки с отрицательными координатами; высота не влияет на чанк; рёбра ↔ ячейки; импорт Z-up |
| Идентификаторы | валидация `PrototypeId`, round-trip, уникальность |
| Мир | атомарность команд; блокировка по ревизии; dirty и ревизии чанков (включая границу чанков); индексы после удаления; round-trip состояния; отказ на повреждённых данных |
| Репликация | порядок, дубли, пропуск, конфликт без изменения состояния |
| Геометрия | габариты по оси Y, батчинг по материалам, одно излучение на границе чанков, нормали и обход |
| Топология | комната/улица, дверь как портал, слияние при разрушении стены, разделение перегородкой, каналы окна, достижимость, диагностика, лимит области |
| Навигация | дверь открыта/закрыта, пролом открывает путь, окна блокируют, лимит поиска |
| Спрайты | 4/8 направлений, поворот камеры, вырожденные входы; RSI: валидные и враждебные файлы |
| Сохранения | снимок, журнал, идемпотентный повтор, оборванный хвост, порча в середине, подмена данных, пропуск `seq`, golden v1, миграции |
| Протокол | round-trip, версия/размер/значения, лишние байты, 20k случайных и 20k мутированных пакетов |
| Bevy | порядок стадий, фиксированный шаг, спавн/удаление сущностей по `ObjectId`, отклонённые команды |
| Сервер | новый мир, скрипт команд, перезапуск с тем же хешем, восстановление из журнала, периодический снимок |
| AC-VS1 | см. `examples/vertical-slice/tests/ac_vs1.rs` |

## Не покрыто (честно)

GPU-рендер, физика (Avian), сетевой транспорт, редактор, навигационные тайлы с
инкрементальным кэшем, fuzz файловых форматов (GLB/YAML), нагрузочные бенчмарки и
бюджеты производительности (AC-013 — после первых репрезентативных сцен).
