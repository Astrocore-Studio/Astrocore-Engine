# План тестирования

## Обязательные проверки (правило 4 раздела 26)

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
./scripts/check-headless.sh
./scripts/render-smoke.sh   # нужны xvfb, mesa-vulkan-drivers, libxkbcommon-x11-0
```

То же выполняет CI (`.github/workflows/ci.yml`) + дымовой запуск сервера.

## Что покрыто

| Область | Проверки |
| --- | --- |
| Координаты | правосторонность Y-up; чанки с отрицательными координатами; рёбра ↔ ячейки; преобразования (поворот, отражение, перенос, точки, поворот объектов); импорт Z-up |
| Идентификаторы | валидация `PrototypeId`, выводимые `ObjectId` |
| Мир | атомарность команд; ревизии; dirty на границах чанков; марши и занятость; свободные модели; удаление этажей; round-trip; отказ на повреждённых данных; репликация |
| Геометрия | габариты, батчинг, ступени/пандусы, сварка углов, коллизионные коробки, **GLB (враждебные файлы, 2000 мутаций)** |
| Топология | комнаты, порталы, слияние при разрушении, каналы, достижимость, диагностика |
| Навигация | двери, пролом, окна, лимит; **этажи и лестницы; кэш тайлов = прямой поиск на случайных картах; инкрементальное обновление** |
| Физика | посадка, стены, скольжение, двери, **подъём по лестницам**, падение, потолок, детерминизм, лучи, пересечения, триггеры, границы чанков, свободные объекты; **слои и маски, shapecast, контакты, подвижные платформы с пассажирами** |
| Рельеф | кисти, интерполяция = треугольники меша, обратимость, репликация, фундамент, дороги, склоны, швы чанков, персонаж на холмах и обрыве |
| Спрайты | 4/8 направлений, орбита камеры; RSI враждебные файлы |
| Префабы | стабильные ID, наследование, вложенность, циклы, версии, обновление без потери переопределений, конфликты, отделение |
| Рантайм | двери, стриминг с проверкой ревизий, активность с удержанием опасных процессов, модули, граф соединений и симуляции |
| Сохранения | снимок, журнал, идемпотентность, оборванный хвост, порча, golden v1, миграции; **обновление карты N→N+1 (слияние, конфликты, политики, идемпотентность, воспроизведение журналом)** |
| Протокол | round-trip, лимиты, 20k случайных и 20k мутированных пакетов |
| Сеть | **хуки движка, репликация данных модулей (интерес, последовательность, поздний вход), доставка содержимого по хешу с бюджетом и проверкой, метрики**, рукопожатие, совместимость, права, ревизии, двери, интерес и видимость через комнаты, бюджет, лимиты, потери и пересинхронизация, предсказание и поправки, интерполяция, TCP и враждебные соединения |
| Компилятор | детерминизм, раздельные пакеты, инкрементальность, совместимость, враждебные пакеты |
| Редактор | undo/redo, откат, инструменты, автоматика, валидатор, префабы, проекты, просмотр, «играть отсюда»; **гизмо (выбор оси, перетаскивание, поворот), различия миров** |
| Studio | состояние окна: инструмент «Модель», инспектор, гизмо с одним шагом отмены, префабы, консоль, различия |
| API | `WorldApi`, `EntityApi` (поколения), `PhysicsQuery`, `AssetRegistry`, `SimulationTopology`, `ReplicationRegistry`, `EditorExtension` |
| Мир (авторские объекты) | зоны, объёмы, порталы, точки: валидация, лимиты, ссылки, удаление, round-trip, старые снимки, репликация |
| Математика | плавающее начало координат: точность вдали от нуля, порог и привязка к чанкам |
| Рендер (расширения) | свет и бюджет теней, излучающие материалы, статистика, дальность отрисовки, слои спрайтов |
| Сервер | пакетный и сетевой режим, восстановление из журнала, метрики |
| Рендер | цвета, конверсия мешей, камеры; **скриншот клиента на программном Vulkan** |
| AC-VS1 | `examples/vertical-slice/tests/ac_vs1.rs`: здание, лестницы, дверь, пролом, два клиента |
