# Сеть

## Что есть

`astrocore-protocol` — сообщения и кодирование, **без транспорта**:

* `ClientMessage`: `Hello`, `Input`, `Interact`, `Edit`, `RequestSnapshot`;
* `ServerMessage`: `Welcome`, `WorldOp`, `InputAck`, `Reject`;
* пакет = `[версия протокола: u16 LE][тело postcard]`;
* лимит пакета 64 КиБ проверяется **до** разбора; версия — до разбора тела;
* после разбора — семантическая проверка (длины строк, оси ввода в `-1..=1`,
  конечный `yaw`); лишние байты — ошибка;
* `PrototypeId` валидируется при десериализации.

Тесты: round-trip всех сообщений, отказ на неверной версии/размере/значениях,
20 000 случайных пакетов и 20 000 мутаций корректных пакетов — без паники.

## Репликация структуры

Сервер рассылает подтверждённые `WorldOp`; клиент применяет через
`World::apply_replicated`: по порядку, идемпотентно; при `Gap` запрашивает snapshot.
Проверено: две реплики сходятся к хешу сервера при дублях и обратном порядке доставки;
операции кодируются компактно (< 200 байт на операцию в срезе).

## Чего нет и что дальше

* транспорт, handshake по сокетам, авторизация, rate limits — ADR-0006 (Proposed);
* prediction/reconciliation, interpolation, interest management (комнаты, этажи,
  приоритеты), передача ассетов отдельным каналом;
* snapshot по сети (сообщение `RequestSnapshot` есть, ответа пока нет).

Клиентским данным доверять нельзя: сервер обязан дополнительно проверять права и
ревизию (`Edit.base_revision` ↔ `World::apply_checked`).
