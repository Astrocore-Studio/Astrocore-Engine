# ADR-0013. Карта — отдельный мир

Дата: 2026-11-19. Статус: **принято** (владелец проекта, 19.11.2026). Отменяет решение
[ADR-0012](0012-maps.md) (карты внутри одного мира, разнесённые по высоте).

## Контекст

Нужны карты как в SS14: у каждой своё пространство и координаты, карты не взаимодействуют,
клиент получает только свою карту, замороженная карта стоит целиком. ADR-0012 держал все карты
в одном `World` на разной высоте: для игрока похоже, но клиент получал все карты сразу, а
изоляцию механик пришлось бы обеспечивать вручную в каждой.

## Решение

1. **Сервер держит несколько миров** — по одному на карту (`MapId`). У карты свой `World`,
   физика, двери, топология и определение `MapDef { id, name, paused, initialized }`. Карта 0
   есть всегда и создаётся из мира, с которым запущен сервер. `GameServer::world()` — мир карты 0.
2. **Игрок на одной карте.** Его позиция — в координатах этой карты. Игроки разных карт друг
   друга не видят (репликация сущностей — только в пределах карты).
3. **Сеть:** снимок, операции мира и состояние дверей уходят только игрокам карты. Перенос на
   другую карту — `ServerMessage::MapChanged`, затем снимок новой карты и позиция; клиент
   забывает мир, двери и чужие сущности прежней (`ClientEvent::MapChanged`).
4. **Хуки модулей вызываются в рамках карты:** `HookContext::world` — мир карты вызова
   (`ctx.map()`): для команды игрока — его карта, для `Tick` — каждая карта по очереди.
   `ctx.players()` — игроки карты, `ctx.all_players()` — все; `ctx.map_of`, `ctx.maps`,
   `ctx.paused`. Просьбы о картах: `create_map`, `remove_map`, `define_map`, `move_to_map`.
5. **Пауза:** тик карты на паузе всё равно приходит (`ctx.paused() == true`), и модуль не
   продвигает её симуляции — так у модуля остаётся место для общего, что не зависит от карты.
6. Внутри сервера одна карта «активна»: её мир лежит в полях сервера, остальные — в стороне;
   переключение (`enter`) — перестановка структур, без копирования.

## Последствия

* Модули, у которых состояние привязано к миру (атмосфера, питание, лужи…), хранят его по
  картам и подставляют в рамках карты вызова.
* Удаление карты переносит её игроков на карту 0 в точку появления.
* Рельеф (`Terrain`) — только у карты 0.
