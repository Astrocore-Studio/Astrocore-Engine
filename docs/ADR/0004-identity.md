# ADR-0004. Идентификаторы объектов

* Статус: **принято** (AC-012)
* Дата: 2026-11-10

## Решение

| Идентификатор | Тип | Где живёт |
| --- | --- | --- |
| `PrototypeId` | строка `namespace:path`, `a-z0-9_-./`, ≤128 | файлы, сеть |
| `ObjectId` | UUID | файлы, сеть, журнал; постоянный |
| `PrefabNodeId`, `PrefabInstanceId` | UUID | определения и экземпляры префабов; вложенный объект = пара `NestedObjectRef` |
| `NetworkEntityId` | `u32` | только внутри сетевой сессии |
| `Entity` (Bevy) | индекс + поколение | только runtime; связь через `ObjectIndex`; не сериализуется |

Запрещено строить постоянный ID из координат, имени, пути файла или индекса ECS.
`PrototypeId` валидируется при десериализации. Отделённый от префаба объект получает
собственный `ObjectId`.

## Последствия

Сохранения, журнал и репликация не зависят от внутреннего устройства Bevy ECS;
перемещение объекта не меняет его идентичность. Префабы (F6) используют те же типы.
