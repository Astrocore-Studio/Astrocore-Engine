# ADR-0001. Bevy как технологический фундамент

* Статус: **принято** (дизайн-документ v1.1, AC-002; пересмотр решения о собственном runtime)
* Дата: 2026-11-10

## Контекст

Версия 1.0 предполагала собственный runtime (winit + wgpu + hecs/flecs). Для команды
неизвестного размера это означало годы работы до первого играбельного результата.

## Решение

Rust + Bevy — основа ECS, расписания, ресурсов, окна и рендера. Astrocore реализует
поверх: канонический мир, структурную геометрию, топологию, протокол, сохранения,
редактор. Собственный рендерер «с нуля» не планируется; пользовательские render-узлы
и материалы — только при доказанной необходимости.

Отказ от Bevy допускается только новым ADR с измеренными блокирующими ограничениями.

## Последствия

* Доменные крейты **не** зависят от Bevy (проверяется `scripts/check-headless.sh`);
  Bevy — адаптер в `astrocore-bevy`. Это держит стоимость возможной замены низкой.
* Сервер собирается с `default-features = false`: без окна, рендера и звука.
* Частые ломающие релизы Bevy → политика обновлений в ADR-0002.
