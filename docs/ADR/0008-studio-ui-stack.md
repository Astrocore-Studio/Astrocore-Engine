# ADR-0008. UI-стек Astrocore Studio

* Статус: **принято**
* Дата: 2026-11-11

## Решение

Окно Studio — приложение `apps/astrocore-studio` **в этом же репозитории** (раздел 19
дизайн-документа: редактор — часть workspace движка; игровые карты и контент в репозиторий не
входят). Стек: Bevy + `bevy_egui =0.43.1` (egui 0.36), рендер мира — `astrocore-render`.

Логика отделена от окна: `StudioState` принимает события указателя и нажатия кнопок и
использует `astrocore-editor`; оболочка только рисует и передаёт ввод. Так поведение инструментов
тестируется без экрана, а замена UI-стека не затрагивает редактор.

## Последствия

* Egui-панели рисуются поверх Bevy-сцены; клики по панелям не попадают в мир (`egui_wants_pointer_input`).
* Версия `bevy_egui` закреплена вместе с Bevy (ADR-0002).
* Шрифты egui по умолчанию (feature `default_fonts`) покрывают кириллицу.
