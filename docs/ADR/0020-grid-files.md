# ADR-0020. Файлы гридов: загрузка на карту и сохранение отдельно

Дата: 2026-11-27. Статус: принято (фаза 6, задача 6.6 плана Build: инструменты маппинга).

## Контекст

Robust умеет загрузить файл грида на существующую карту со сдвигом и поворотом
(`loadgrid`, `MapLoaderSystem.TryLoadGrid`) и сохранить один грид (`savegrid`,
`TrySaveGrid`). Так в SS14 строят шаттлы и станции-вставки, а маппинг грида сохраняется
автоматически. Файл грида — тот же формат: `meta.category: Grid`, `maps: []`, один грид в
`grids` и `orphans`, у грида `Transform.parent: invalid`.

У нас загрузчик понимает только файлы карт, а сохранение — только карту целиком.

## Решение

1. **`load_grid(root, map, offset, rotation, initialize)`** загружает файл, в котором ровно
   один грид и нет карт, на существующую карту: грид становится её потомком, его положение
   поворачивается вокруг начала карты и сдвигается (`ApplyTransform` Robust для сущностей
   прямо на карте). `parent: invalid` читается как «без родителя». Сущности файла вне карт
   (`nullspace`) сохраняются вместе с этим гридом. Номера тайлов файла запоминаются на гриде.
2. **`save_grid(grid, options)`** пишет грид со всеми потомками и его сущностями вне карт:
   `category: Grid`, `maps: []`, грид в `grids` и `orphans`, у грида `parent: invalid`
   (родитель — карта — в файл не входит). Номера сущностей и тайлов — как при сохранении
   карты; `MapSave::uids` отдаётся игре (ADR-0019).
3. Загрузка в инициализированную карту даёт сущностям `MapInit`, в неинициализированную —
   нет; пауза — по карте, как при размещении.

## Последствия

- Игра переносит `loadgrid`, `savegrid` и автосохранение гридов при маппинге.
- Файл карты по-прежнему грузится только `load_map`: слияние карты с картой (`MergeMap`)
  пока не нужно.
