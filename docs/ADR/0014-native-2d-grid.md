# ADR-0014. Нативный 2D-мир Astrocore

Astrocore переходит на 2D как основное направление. У тайла целочисленные координаты
по X и Y. Положение подвижного объекта непрерывно и выражено в тайлах, ось Y направлена
вверх. Engine отвечает за сетку, коллизии и сетевой сеанс. Build определяет игровой
контент и правила.

`astrocore-grid2d` принимает ввод, выполняет серверный тик 20 Гц и рассылает
состояние. Сеанс использует существующий транспорт Lightyear с отдельной версией
протокола. При входе клиент получает карту и текущий снимок по надёжному каналу.
Дальше клиент принимает свежие снимки состояния. Возврат к более старому снимку
запрещён номером тика. Такой обмен подходит для небольшого первого среза.

Build загружает станцию и прототипы из RON. Карта и каталог передаются при входе.
Сервер проверяет движение, дальность действий, занятость проёмов и состояние рук.
Сеанс Engine принимает типизированную игровую команду Build по надёжному каналу
и направление движения по последовательному каналу. Build ведёт фазы раунда,
атмосферу и питание, а графический клиент отображает состояние сервера.

В раунде Build изменяет рабочую копию тайловой сетки. Сервер использует её
для коллизий и пересчёта газовых рёбер. В снимок входят изменения к исходной
сетке и их ревизия. При новом раунде Build восстанавливает исходную сетку.
Редактор сохраняет исходную карту в формате загрузчика Build.

Активная сборка проекта — 2D. Корневая команда `cargo play` в Build запускает
локальный сервер и клиент. План разрушаемого 3D-мира из ADR-0004 Build
относится к истории проекта.
