# ADR-0012. Несколько карт в одном мире

Дата: 2026-11-19. Статус: **отменено** [ADR-0013](0013-maps-as-worlds.md) (владелец выбрал карты как отдельные миры).
Первоначально принято владельцем 19.11.2026.

## Контекст

Игре нужно несколько карт одновременно, как в SS14: станция, ЦК, шаттлы, карта, которую
маппер строит, пока на станции идёт раунд. У карты свой номер и состояние: **на паузе**
(заморожена — симуляция стоит, маппинг идёт на замороженной карте) и **инициализирована**
(разовая «оживляющая» настройка уже прошла; сохранять в файл нужно неинициализированную карту).
Команды SS14: `mapping <id> [путь]`, `loadmap <id> <путь>`, `savemap <id> <путь>`,
`pausemap`/`unpausemap`, `mapinit`, `rmmap`.

Сервер движка держит один `World`: на нём построены сеть (снимок + операции), физика, двери,
топология, интерес и все игровые модули (`HookContext::world`).

Рассматривались:

* **несколько `World` на сервере** — у каждой карты свой мир, клиент получает только мир своей
  карты и при переходе — новый снимок. Чисто, но переписываются сеть, хуки и все игровые модули
  (каждая механика держит состояние по одному миру);
* **карты внутри одного `World`** — карта — именованная группа этажей со своими флагами; карты
  разнесены по высоте, поэтому физика, интерес и атмосфера их не смешивают. Сеть, хуки и модули
  остаются, модули учат флаг паузы.

## Решение

1. **Карта — группа этажей одного мира.** `MapDef { id: MapId, name, paused, initialized }`;
   у этажа поле `map` (по умолчанию `MapId(0)`). Карта 0 существует всегда (неявно, если не
   задана): старые миры — одна карта 0 без изменений.
2. **Команды мира:** `DefineMap(MapDef)` — создать карту или обновить её имя и флаги;
   `RemoveMap { id }` — удалить карту со всеми её этажами, элементами и авторскими объектами
   одной операцией. Операции реплицируются как обычно — клиент применяет их так же.
3. **Карты разнесены по высоте** — это решает игра, задавая `base_y` этажей (Build: карта `k`
   на высоте `k × 1000` м). Физика, интерес (игроки разных карт далеко друг от друга) и
   атмосфера по этажам карты не смешивают без дополнительного кода.
4. **Пауза — флаг для симуляций.** Движок хранит и реплицирует `paused` и `initialized`,
   отвечает на вопросы «какой карте принадлежит этаж» и «стоит ли карта»; игровые модули сами
   не продвигают состояние на замороженной карте. Правки маппинга на замороженной карте разрешены.
5. **Снимок:** `WorldState.maps` и `FloorDef.map` с значениями по умолчанию; схема и хеш
   содержимого старых миров не меняются (пустой список карт и карта 0 в хеш не входят).

## Последствия

* Клиент получает снимок всего мира, со всеми картами; рисовать стоит только карту, где он
  находится (фильтр по этажам карты). Снимок по карте — оптимизация на потом.
* Переход между картами — телепорт на высоту другой карты.
* Если понадобится больше изоляции (разные правила физики или своя сеть на карту) — переход к
  нескольким `World` новым ADR; команды и формат карты от этого не меняются.
