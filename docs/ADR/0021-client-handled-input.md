# ADR-0021. Ввод, обработанный клиентом, на сервер не отправляется

Дата: 2026-11-28. Статус: принято (фаза 7 плана Build, задача 7.2: перетаскивание для криокапсул).

## Контекст

До этого клиент вызывал свои обработчики функции ввода и всегда отправлял команду серверу.
В Robust иначе (`InputSystem.HandleInputCommand`): если клиентский обработчик вернул
«обработано», команда на сервер не идёт; отложенную команду клиент может повторить
(`replay`) — тогда отложивший её обработчик второй раз её не берёт.

На этом стоит перетаскивание SS14 (`DragDropSystem` клиента): нажатие «Использовать» над
перетаскиваемой сущностью клиент забирает себе; если мышь увели — шлёт серверу запрос
перетаскивания, если нет — повторяет нажатие и отпускание, и сервер получает обычный щелчок.
С прежним поведением сервер выполнял бы щелчок сразу при нажатии (подбирал предмет, который
тащат на стол, взаимодействовал с телом, которое кладут в криокапсулу).

## Решение

1. `send_input` вызывает обработчики клиента и отправляет команду серверу только если её
   никто не обработал. Возвращает `true`, если обработана клиентом.
2. `replay_input` делает то же с признаком повтора: `InputArgs.replay = true`. Обработчик,
   отложивший команду, проверяет признак и повтор пропускает.
3. На сервере признак всегда `false`.

## Последствия

- Клиентские обработчики, которые возвращали «обработано» и при этом ждали, что сервер тоже
  получит команду, должны вернуть «не обработано». В Build таких нет: осмотр и горячая
  панель отправляют серверу свои сообщения сами.
- Перетаскивание и другие отложенные щелчки переносятся как в SS14.
