# ADR-0002. Матрица совместимых версий и политика обновлений

* Статус: **принято**
* Дата: 2026-11-10

## Матрица

| Зависимость | Версия | Основание |
| --- | --- | --- |
| Rust | stable, не ниже **1.97.1** (проверено на 1.99.1) | `bevy 0.20.1` и `lightyear 0.31.0` требуют rustc 1.97.1 |
| bevy | `=0.20.1` (`default-features = false`) | `astrocore-bevy`, `astrocore-server` (без графики); `astrocore-render`/`astrocore-client` — с рендером и `x11`, проверено скриншотом на программном Vulkan |
| avian3d | 0.8.0 (требует bevy ^0.20) | подключён адаптером `astrocore-physics-avian` (ADR-0009); собственный слой остаётся для контроллера персонажа |
| lightyear | 0.31.0 (bevy_app/bevy_ecs ^0.20) | подключён транспортом `astrocore-lightyear` (ADR-0010) |
| bevy_egui | 0.43.1 (bevy ^0.20) | совместимость по метаданным реестра; **не** собиралась |
| glam | 0.33 (как у `bevy_math 0.20.1`) | совпадение версий типов |

**Smoke-проверка (10.11.2026):** отдельный пакет с зависимостями
`bevy =0.20.1`, `avian3d =0.8.0` (`3d`, `parry-f32`, `default-collider`) и `lightyear =0.31.0`
успешно проходит `cargo check` на rustc 1.99.1. Это подтверждает, что версии
разрешаются и компилируются вместе; **интеграционные тесты физики и сети не
писались** — они относятся к фазам F3/F4.

В рабочем дереве подключены Bevy, Avian (ADR-0009) и Lightyear (ADR-0010).

## Политика обновлений

1. Версии Bevy-семейства закреплены (`=`) в `[workspace.dependencies]`, `Cargo.lock` в репозитории.
2. Обновление Bevy — отдельный PR («migration PR»), без функциональных изменений.
3. Обновляемся, когда **все** используемые зависимости (Bevy, Avian, Lightyear,
   bevy_egui) имеют совместимые релизы, и не чаще чем раз в два релиза Bevy, если
   нет нужной правки.
4. В migration PR обязательны: полный `cargo test --workspace`, `check-headless.sh`,
   сравнение производительности на эталонных сценах (когда появятся).
5. Зависимости обновляются только после проверки по реестру, а не «по памяти».
