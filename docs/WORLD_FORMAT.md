# Формат мира

## Координаты (ADR-0003)

* метры;
* правосторонняя система, **Y — вверх**, горизонталь — X/Z, «вперёд» — −Z (как в Bevy);
* ядро, рендер, физика и навигация используют одну систему осей — конвертеров нет;
* преобразование допустимо только в импортёрах (`astrocore_math::import`):
  Z-up → Y-up и 2D-карта `(x, y)` → `(x, высота, y)`.

## Сетка

* Шаг сетки — `WorldConfig::grid_step_m` (по умолчанию 1 м).
* `GridCell { x, z }` покрывает `[x·step, (x+1)·step) × [z·step, (z+1)·step)`.
* Стены и проёмы лежат на рёбрах `GridEdge { x, z, dir }`:
  `AlongX` — от `(x,z)` до `(x+1,z)`; `AlongZ` — от `(x,z)` до `(x,z+1)`.
* Размер чанка — `chunk_size_m` (по умолчанию 32 м), обязан быть кратен шагу сетки.
  Чанк задаётся парой `(x, z)`; высота в индекс чанка не входит.
* Ребро на границе чанков принадлежит обоим (dirty и индекс), но геометрию
  эмитит один — чанк «максимальной» из смежных ячеек.

## Этажи

`FloorDef { id, name, base_y, height }` — редакторская группировка с диапазоном
высот по Y. Высота этажа не связана с шагом сетки. Этаж — не отдельная плоскость.

## Структурные элементы

`StructureElement { id, kind, placement, floor, material, thickness }`

| Вид | Размещение | Место (слот) |
| --- | --- | --- |
| `Wall` | ребро | ребро этажа |
| `Opening(Door \| Window)` | ребро | то же ребро — проём **вместо** стены |
| `Floor` | ячейка | перекрытие ячейки |
| `Ceiling` | ячейка | потолок ячейки |

В одном слоте — один элемент. `thickness` ∈ (0, шаг сетки]. Размещение вида в
неподходящем месте (стена в ячейке и т. п.) отклоняется.

## Ревизии и операции

* `World::revision()` — число применённых команд.
* `WorldOp { seq, command }`, `seq` — ревизия после применения; последовательность
  непрерывна. Повтор (`seq ≤ ревизии`) — `Duplicate`; пропуск — `Gap`; конфликт с
  локальным состоянием — `Rejected` (состояние не меняется).
* `apply_checked(cmd, expected)` — оптимистичная блокировка для редакторов.
* `content_hash()` — FNV-1a 64 по каноническому JSON состояния; для сравнения миров и
  проверки совместимости клиента и сервера.

## Сериализуемое состояние

`WorldState { schema_version, id, config, floors, elements, revision, chunk_revisions }`.
Производные индексы и dirty-флаги не сохраняются и пересобираются при загрузке.
`World::from_state` повторно валидирует всё: дубли ID и слотов, неизвестные этажи,
ревизии чанков больше ревизии мира, неверную конфигурацию. Версия схемы мира — 1.

## Пока не реализовано

Лестницы и пандусы, крыши, балки, свободные меши (GLB), ландшафт, префабы,
регионы и уровни активности (active/reduced/dormant), связи между этажами.
